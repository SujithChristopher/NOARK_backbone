# Camera calibration and accuracy

This folder groups camera calibration tools, calibration configurations, notebooks, and experiments.

- `programs/`: maintained calibration utilities.
- `configs/current/` and `configs/old/`: current and archived TOML configurations.
- `dual_notebooks/`: stereo calibration and camera accuracy workflows.
- `experiments/`: trial calibration implementations and result files.
- The other notebooks in this folder cover mono, fisheye, and calibration accuracy analysis.
- Calibration capture programs remain in `recorder/`.
